# pinecall-tenancy

Who: an org, its people, their keys, its secrets and quotas, and the letters it sends: `pinecall.orgs`, `pinecall.auth`, `pinecall.accounts`, `pinecall.mail`.

One of the distributions the Pinecall runtime is released as, at one version; `pip install
pinecall` installs them all. What it is, and why: docs/multi-tenancy.md, docs/limits.md.
