# pinecall-testkit

What every suite of the Pinecall runtime leans on: the ring-0 plugin (dead vendor keys, no `.env`,
the budget a search gets), the Postgres fixtures, the clocks, the tree the layout rules read, and
the fakes more than one distribution's suite needs — an LLM, a room, a media plane, an identity
provider, a mail server, memory and knowledge answering from a script.

A development dependency of the workspace. It is never published.
