# pinecall-channels

How a call reaches Pinecall: a number, a trunk, a room token, a WhatsApp thread: `pinecall.routes`, `pinecall.telephony`, `pinecall.tokens`, `pinecall.whatsapp`.

One of the distributions the Pinecall runtime is released as, at one version; `pip install
pinecall` installs them all. What it is, and why: ARCHITECTURE.md §7, docs/protocol/codes.md.
