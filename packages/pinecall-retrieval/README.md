# pinecall-retrieval

What a Pinecall agent knows and remembers: contact memory, the knowledge base, the lookups: `pinecall.memory`, `pinecall.knowledge`, `pinecall.lookups`.

One of the distributions the Pinecall runtime is released as, at one version; `pip install
pinecall` installs them all. What it is, and why: docs/retrieval/spec.md.
