# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be kind, be direct, argue about the code and not about the person, and
assume the other side wants the same thing you do — a runtime that answers the telephone well.

Harassment, discrimination and personal attacks are not welcome in issues, pull requests,
reviews or anywhere else this project meets. Report a problem privately to the maintainer at the
address in `pyproject.toml` (`authors`); it will be read, kept confidential, and acted on. The
maintainer may edit or remove a contribution and ask a contributor to leave.
